## Resource and timing evidence

The [retention run](extension/output/playwright/soak-result.json) ran from **20:06:44.841 to 20:36:44.957 UTC**, lasting **1,800.116 seconds** with **60 samples**. Both fixture tabs remained in deep mode in every sample. Evidence checkpoint size ranged from **176,786 to 195,324 bytes**; sampled instrumented-page JavaScript heap ranged from **2,281,324 to 5,208,616 bytes**. These values do not measure total app/browser memory or saved-media growth.

That run started before subsequent focus/spatial fixes. Its instrumented page was not selected while the baseline was selected, making its timer-overhead comparison invalid. The final sample's timer p95 was **97.3 ms armed versus 1.1 ms baseline**; this result is retained with its confound, not discarded. A [same-tab selection control](extension/output/playwright/tab-selection-control/soak-result.json) reproduced p95 **1.1 → 52.2 → 1.0 ms** as the fixture was selected, deselected, and selected again with unchanged collection/workload. `document.visibilityState` still reported visible; selected-tab scheduling is the observed distinction.

The [120-second comparison with both fixture tabs selected](extension/output/playwright/visibility-comparison/soak-result.json) measured final timer p95 **1.0 ms armed / 1.1 ms baseline** and request p95 **3.7 / 3.8 ms**. A [same-browser paused/armed/paused control](extension/output/playwright/collection-control/soak-result.json), keeping page/process topology constant, measured:

| Phase | Chrome CPU, percent of one core | Timer p95 | Sum of Chrome process RSS |
|---|---:|---:|---:|
| Paused | 4.56% | 1.3 ms | 1,076,576 KiB |
| Armed | 7.58% | 1.4 ms | 1,107,312 KiB |
| Paused again | 4.21% | 1.3 ms | 1,033,104 KiB |

CPU covers the fixture Chrome processes. RSS sums may count shared pages more than once; the armed snapshot rose **30,736 KiB**, approximately 30 MiB, relative to the first paused snapshot. These short controls quantify the local fixture, not the complete native workflow.
